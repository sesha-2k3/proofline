# Decisions

- B1: Routers are registered through a `ROUTERS` list in `app/main.py`; it starts empty and later steps append to it.
- B1: The SPA fallback is a catch-all GET route registered after `/api` and `/samples`; it returns 404 for `/api/*` and `/samples/*`.
- B3: `rules_version()` returns `meta.last_reviewed` from rules/masshealth.yaml; the loader also rejects any non-null source not in `SOURCES`.
- B4: Mock records use the sample file name as `docId`; POST /documents replaces it with the request `doc_id`. Multipart form fields are named `file`, `doc_id`, `doc_type_hint` (snake_case, as in BUILD_PLAN).
- B4: Mock pipeline trace: all six stages "ok" for recognized files; for unknown files ingest/render "ok" and the rest "skipped", extractor "none", classificationConfidence "low".
- B4: Mock thresholds in Jorge data (shortfalls, "80"/"$580" in messages) are computed from rules accessors, not literals. Spanish summaries are in `SUMMARIES` in app/mocks/jorge.py.
- B4: POST /packet and /timeline return `application/pdf` with Content-Disposition attachment; no JSON response model.
- B5: Ledger collapses duplicate records (same doc_type, issuer case-insensitive, period start/end) before evaluating; it keeps a countable copy first, then the smallest id. Dropped duplicates appear in neither id list.
- B5: Volunteer records count only when org_type is in `allowed_volunteer_org_types()` and non_partisan is true (rule volunteer_org_requirement); ineligible ones are neither counted nor excluded (validation flags them in B10).
- B5: Income uses doc_type: gig_earnings → gig gross/net; paystub/employer_statement → employee gross; volunteer/school activities give no income. Gig net per month = max(0, gross share − expenses share), with gross and expenses split separately.
- B5: Proportional split rounds half up in integer arithmetic. A record counts in every window month its period overlaps. best_month is None only when there are no months to evaluate.
- B6: ground_truth.json is `{ "files": { <sample name>: { docType, records: [EvidenceRecord camelCase], notice: NoticeInfo | null } } }`; long lines shrink the font to stay on one line; PDFs are built with reportlab invariant=1 so reruns produce the same bytes.
- B7: Ingest accepts by extension (.pdf/.png/.jpg/.jpeg); MIME must match unless empty or application/octet-stream; files that won't open are UNSUPPORTED_FILE (HTTP 415). Keyword ties → no match (falls to LLM or "unknown"). Classification confidence: hint/keywords "high", LLM "low"; the LLM classifier is an injected client (B8 `LlmClient`) and returns None in demo mode. Images always render to PNG; PDF page images only when requested.
- B8: Raw extraction models (`RawField`/`RawRecord`/`RawNotice`/`RawExtraction`, snake_case keys matching EvidenceRecord) live in `pipeline/extract/models.py`; the stage entry `extract()` (template → LLM → none with warning "Enter the values manually.") is in `pipeline/extract/__init__.py`. Values stay raw ("$320.00", "04/01/2027"); volunteer month lines ("May 2027 hours") give ISO period dates. The "[handwritten" mark lowers only the value read from that line (hours), not the period taken from the printed month label, to match ground_truth.json. LLM transport errors count as a failed attempt and give up with no records.
- F1: Frontend pins TypeScript ~5.9 (Vite template default is 6.x) because openapi-typescript 7 requires a TypeScript 5 peer.
